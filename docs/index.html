🔴 ingress-nginx is retired

kubernetes/ingress-nginx was archived on March 24, 2026. The repository is read-only and the final release is controller-v1.15.1. Migrate to the Gateway API with a maintained implementation (Cilium, Envoy Gateway, or Istio). Kubernetes SIG-Network's ingress2gateway tool can convert existing manifests.
