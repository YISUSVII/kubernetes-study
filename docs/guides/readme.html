Kubernetes Study Repository

A structured study guide covering production-grade Kubernetes tooling, updated for October 1, 2026. Study baseline: Kubernetes 1.35 / 1.36. Upstream also maintains 1.37; check each add-on's support matrix before upgrading.

🌐 Website: browse this repo as a visual, searchable site at https://yisusvii.github.io/kubernetes-study/ (source in docs/). To enable it on your own fork: repo Settings → Pages → Source: Deploy from a branch → Branch: main / folder: /docs.

⚠️ Deprecation notice: ingress-nginx (the project used in nginx-ingress-setup.md) was archived/retired by Kubernetes on March 24, 2026. See DEPRECATIONS.md for details and migration guidance before using it in new projects.

Website content

The website keeps setup guides, learning paths, admin references, and YAML examples on the site as styled HTML pages. Each learning path opens its section of the complete study guide. Manifest pages include copy and download controls.

Markdown files and examples/ remain the source of truth. After changing them, regenerate the website and commit the generated files in docs/:

python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_site.py
python3 scripts/check_site.py

Preview locally with python3 -m http.server 8765 --directory docs, then open http://localhost:8765/. GitHub Pages continues to serve main → /docs; no server or runtime Markdown dependency is needed.
